# Samples

## Estructura

- `in/`: frames de entrada para pruebas
- `out/`: frames decodificados
- `bitstreams/`: archivos `.rtv`

## Recomendación
Mantener muestras pequeñas, reproducibles y con nombre descriptivo:
- `flat_gradient_128x72`
- `moving_square_160x90`
- `camera_pan_small`

Evitar subir muestras pesadas al repositorio principal.
