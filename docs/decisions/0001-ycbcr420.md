# ADR 0001: Uso de YCbCr 4:2:0 de 8 bits

## Estado
Aceptado

## Contexto
RTVid v0 necesita un formato interno suficientemente estándar en lo matemático, pero simple y operativo para una primera implementación portable.

## Decisión
Usar YCbCr 4:2:0 de 8 bits como representación base en v0.

## Razones
- equilibrio entre complejidad y compresión
- menor volumen de datos que RGB 4:4:4
- base clásica para predicción y transformada
- suficiente para un prototipo funcional

## Consecuencias
- la conversión RGB->YCbCr es obligatoria en la ingesta externa
- el decoder puede exportar a RGB para visualización
- futuras extensiones podrían incluir 4:2:2, 4:4:4 o 10-bit
