# ADR 0002: Bloque base 8x8

## Estado
Aceptado

## Contexto
La v0 necesita una unidad de predicción y transformada simple, bien entendida y fácil de portar.

## Decisión
Usar bloques 8x8 como unidad base de predicción y transformada.

## Razones
- simplicidad de implementación
- DCT 8x8 común y clara
- buen balance entre granularidad y complejidad
- evita introducir árboles de partición desde el inicio

## Consecuencias
- menor adaptabilidad que particiones variables
- parser y bitstream más simples
- futura evolución posible a quadtree o unidades mixtas
